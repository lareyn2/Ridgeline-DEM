# Ridgeline / Fundamental Data — Biomerica Transaction
## Authorities Knowledge Base

Primary legal text and accounting guidance for the Fundamental Data LLC /
Biomerica, Inc. business combination. Assembled September 3, 2026.

**Every item here is either text Lewis Reynolds uploaded or pasted, or text
retrieved from the official source named in that item's header. Nothing is
reconstructed from memory.**

## Standing rules

1. Every new code section, regulation, rule or accounting-guidance pull gets
   appended here. Bump the version and update the "still missing" list.
2. Whenever a pull is requested, the request carries **the URL and the
   step-by-step instructions in the same message**. Never a pointer back to a
   URL given earlier in a conversation. Where the target's structure is not
   actually known, say so and give a workaround.
